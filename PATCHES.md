## Remaining boundaries and maintenance

No full fresh production-backup restore, end-to-end S3/RabbitMQ/beat/browser journey, final JS runtime image, production Compose migration or VPS rollout has been qualified. Raw native findings remain in `records/native-findings.json`, with conditional applicability and re-review requirements in `research/current-vulnerabilities.md`; no blanket suppressions or absolute clean claim are made. Plaintext API-token storage/scopes, service-secret rotation, historical data/log cleanup, backup automation, CSP, SSH/operator/monitoring and independent audit remain separate work.

Keep patch scope reviewable. On an upstream/tag/tool/lock/image change, perform intake first, reconcile the full Git delta and package entrypoints, update source-hash backport gates/notices, revalidate independent stores, repeat changed and related positive/negative controls, and assess migrations/restore/rollback before deployment. Code, database format, broker protocol, root policy and runtime compatibility can drift independently. Root distrust can break legitimate dependencies; local native backports and alternate Bun execution increase maintenance cost. Official-image provenance, five-day-old ClamAV signatures, prebuilt binaries and unproven native call graphs remain explicit trust limits.
